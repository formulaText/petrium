# ペトリウム Petrium

Three.js製のブラウザゲーム（試作）です。

- 公開版（mainブランチ）: https://formulatext.github.io/petrium/
- 開発版（devブランチ）: https://formulatext.github.io/petrium/dev/

ゲーム本体は `petrium-prototype.html`、`index.html` はそこへ移動するだけのページです。
main または dev に変更が入ると、GitHub Actions が自動で `gh-pages` ブランチを作り直し、GitHub Pages に反映されます。
